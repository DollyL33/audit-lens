# Audit Lens

**Let your data speak. See it through an auditor's eyes.**

**Try it live:** https://audit-lens.streamlit.app (download [`sample_data/messy_sales.csv`](sample_data/messy_sales.csv) to test it)

Audit Lens is a Streamlit app for internal and forensic auditors. Upload a messy CSV or Excel file, approve the suggested clean-up, and get an audit dashboard:

- **Suggested fixes with tick boxes.** Mixed date formats, `$1,250`-style amounts, messy names and blanks are spotted. You choose which fixes to apply and see a before/after preview. Duplicates are never deleted, because they're evidence.
- **Number cards, a monthly comparison and the biggest transactions.**
- **Benford's Law first-digit test** using Mark Nigrini's Mean Absolute Deviation (MAD) conformity bands and per-digit z-tests.
- **Same-same-same duplicate test** (Nigrini): same amount, same date, same customer/vendor.
- **A "question to ask" for every finding**, the auditor's next step.

Methods follow Mark J. Nigrini, *Forensic Analytics* and *Benford's Law: Applications for Forensic Accounting, Auditing, and Fraud Detection* (Wiley).

## Run it

Requires Python 3.12+.

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Open http://localhost:8501 and upload `sample_data/messy_sales.csv`.

### Optional: smarter fix suggestions

Copy `.env.example` to `.env` and add a free key from [build.nvidia.com](https://build.nvidia.com):

```
NVIDIA_API_KEY=nvapi-...
```

With a key, a model hosted by NVIDIA suggests the fixes (it only picks from a fixed menu, and pandas applies them). Without a key, or if the call fails, built-in rules suggest them instead. The app works either way. The model is sent the column names and the first 20 rows only.

## Sample data

Everything in `sample_data/` is **made up**, generated by `scripts/make_sample_data.py`:

- `messy_sales.csv`: ~1,200 invoices with messy formats, 6 planted duplicates, and a planted cluster of amounts just under a $5,000 approval limit (Benford's flags digit 4).
- `clean_natural.csv`: tidy invoices that follow Benford's Law (the "looks normal" case).

## Project layout

```
app.py                 Streamlit page: upload → review → dashboard
auditlens/loader.py    read CSV / Excel
auditlens/fixes.py     the fix menu, built-in suggestion rules, applying fixes
auditlens/suggest.py   NVIDIA-hosted model suggestions, falling back to the rules
auditlens/detect.py    find the amount / date / customer / invoice columns
auditlens/metrics.py   number cards, monthly totals, top transactions
auditlens/benford.py   Nigrini first-digit test
auditlens/duplicates.py Nigrini same-same-same test
auditlens/questions.py "Question to ask" wording
auditlens/ui.py        dark theme, cards and charts
```
