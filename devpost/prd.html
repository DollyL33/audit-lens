Audit LensProduct requirements

Upload a messy spreadsheet, approve the suggested clean-up, and get a dashboard that looks at your data the way an auditor would. Built for anyone who has data and wants insights from it, without doing the reporting by hand.

Scope → PRD: scope said "the app shows a dashboard with audit findings." Now we know exactly what that means: 4 number cards, a monthly comparison, the top 5 transactions, Benford's and duplicates, each finding ending with a question to ask.

Behaviors

  • 4 number cards: total, count, biggest, change vs last month
  • Monthly comparison chart
  • Top 5 biggest transactions
  • Benford's: actual vs expected, odd digits highlighted, verdict
  • Duplicates listed with counts, caught even if they differed only by messy spacing
  • Every finding ends with a question to ask

How we'll know

  • Card values match totals worked out by hand
  • A planted digit spike gets flagged; natural data says "looks normal"
  • All planted duplicates are listed; none says "No duplicates found"

What if…

Wrong file type or unreadable file
Friendly message; stays on the upload stage.
No date column
Everything else shows. The monthly comparison and month-change card are replaced by: "No date column found, so the monthly comparison isn't available."
No amount column
Shows what it can (e.g. duplicates) and explains that number cards, comparison and Benford's need amounts. If nothing can be analysed, it says so plainly.
Too few amounts for Benford's
Shows a note instead of a misleading verdict. Assumption: under ~50 amounts is too few; we'll confirm in the spec.
Nothing to clean
"Your data looks clean," then continue.
Closing the app
Nothing is saved. A new upload starts fresh.

Look and feel

Borrowing from PandasAI
  • Dark navy background
  • Big bold headline, grey second line
  • Rounded number cards with small uppercase labels
  • "Insight"-style finding cards with a coloured accent
Avoiding
  • Any "AI" wording on screen
  • Chat boxes / "ask a question" inputs
  • Robot or assistant imagery

Building now vs. later

Building now
  • One page: upload → spot the mess → review with tick boxes and before/after → dashboard
  • CSV and Excel, one at a time; automatic column detection
  • Number cards, monthly comparison, top 5 transactions
  • Benford's and Duplicates findings with a verdict and a question to ask
  • Friendly handling of missing columns, wrong files, clean files
Deferred
  • Changing the detected columns by hand
  • Downloading the cleaned file or a report
  • Saving past uploads
Not doing
  • Chat / "ask your data": not part of the core loop
  • Live dashboards, decision trees, shared metrics: enterprise features
  • Other file types, accounts, deployment: cut in scope

Open questions (for the spec)

• How strict is "duplicate": all columns identical, or key fields like invoice + date + amount?
• Minimum number of amounts for a meaningful Benford's check
• Exact headline wording (during the build)
