Audit LensTechnical blueprint

How this works, in plain language

Audit Lens is one Python program built with Streamlit, which turns a Python script into a web page. Every click makes Streamlit run the script again. A small memory box called session state remembers the file, the fixes and the current stage between re-runs, until the tab closes.

The AI only chooses fixes from a fixed menu; pandas makes the changes. If there's no NVIDIA key or the AI misbehaves, built-in rules take over. The user never sees the word "AI." The audit checks follow Mark Nigrini's forensic analytics methods.

The audit maths (Nigrini)

Benford's first-digit test: how the verdict is chosen

MAD = the average gap between actual and expected digit percentages. Drag to see which verdict each MAD value gets, using Nigrini's first-digit bands.

0 · 0.006 · 0.012 · 0.015 · 0.025+
MAD 0.0040 → Close conformity (looks normal)
Which bars light upZ-test per digit with continuity correction; z > 1.96 and above expected = spike.
Sample sizeAmounts ≥ 10 only. Under 100 → skipped. 100–999 → "small sample, read with caution."
Duplicates: same-same-sameSame amount + same date + same customer/vendor (or invoice). Run after clean-up.

What could break, and what happens

NVIDIA key missing, quota used up, slow, or a weird reply
Built-in rules are used silently. Same review screen.
Wrong or unreadable file
"Audit Lens reads CSV and Excel files…" and stays on upload.
Columns not found
Each section that needs a missing column shows a "not available" note.
Fewer than 100 amounts
Benford's shows "Too few amounts for a reliable test" instead of a verdict.
